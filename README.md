# Comanda
Aplicação em C++ de um sistema de comanda de um restaurante como projeto do treinamento da liga acadêmica de tecnologia PUC Tech

## Sistema de Gerenciamento de Comandas de Restaurante
Este é um sistema de gerenciamento de restaurante baseado em terminal, desenvolvido em C++. O programa foi projetado para gerenciar comandas abertas, permitindo edições, exclusões e cancelamentos. O controle de status e a visualização gráfica da comanda têm o intuito de serem feitos em tempo real através de um struct que armazena todas as informações.
